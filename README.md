# AstraEmojis

A standalone, resource-pack-free sprite emoji plugin for **Paper/Minecraft 1.21.9+** (Java 21). It contains no donut-shop, economy, or shop code.

## What was found in `GGDonutShop.jar`

The relevant implementation is in two classes:

* `SpriteComponentReplacer` parses `<sprite:...>` and `:name:` tokens. Its six older custom entries use private-use font glyphs.
* More importantly, `NxSpriteResolver` creates modern Adventure object components with `Component.object(ObjectContents.sprite(atlas, sprite))`. It selects Minecraft's built-in `minecraft:items` or `minecraft:blocks` atlas and item/block sprite path. This is the no-resource-pack rendering path used by the shop dialogs.
* `NxSpriteResolver` optionally delegates to `dev.nx.emojis.api.NxEmojisApi`, but falls back to native sprite objects. `PaperDialogue` inserts the resulting components into Paper dialogs.

AstraEmojis now uses that native sprite-object method for item/block emojis. For example, `:netherite_sword:` becomes an object component referencing the built-in `minecraft:items` atlas and `minecraft:item/netherite_sword` sprite. No PNG is downloaded and no resource pack is sent.

Sprite object components were introduced by Minecraft 1.21.9. They cannot work on 1.21.8 or earlier clients.

## Build

Requirements: JDK 21 and internet access for Gradle dependencies.

```bash
gradle clean build
# build/libs/AstraEmojis-1.0.0.jar
```

The project compiles against Paper 1.21.11. Install ProtocolLib 5.3+ for packet-level interception of UI generated by other plugins.

## Setup

1. Put `AstraEmojis-1.0.0.jar` in `plugins/` on a Paper 1.21.9+ server.
2. Install a ProtocolLib build compatible with that server version if packet interception is wanted.
3. Start the server and edit `plugins/AstraEmojis/emojis.yml` as needed.
4. Run `/emoji reload`.
5. Use `:lime_wool:`, `:pink_harness:`, `:netherite_sword:`, or any other Bukkit material name.

`auto-material-emojis: true` registers all non-legacy Bukkit items and blocks. Custom aliases can point to a built-in sprite:

```yaml
emojis:
  my_donut:
    atlas: "minecraft:items"
    sprite: "minecraft:item/cookie"
    permission: "astraemojis.use.my_donut"
```

The atlas is inferred from `item/` or `block/` if omitted.

### Optional custom PNG mode

A true custom image that does not exist in Minecraft cannot be displayed without a resource pack. The older Unicode/PNG generator remains optional for that case. Set `resource-pack.enabled: true`, add a `char` mapping and matching PNG, and configure hosting. It is disabled by default and is not used by item/block sprites.

## Commands and permissions

| Command | Purpose |
|---|---|
| `/emoji list [page]` | Clickable, paginated list of available emojis |
| `/emoji reload` | Reload mappings and interception configuration |
| `/emoji give <name>` | Give a paper token showing/copying a shortcode |
| `/emoji pack` | Re-send the optional custom-image pack |

* `astraemojis.use` — base permission
* `astraemojis.use.<name>` — per-emoji permission
* `astraemojis.use.*` — every emoji
* `astraemojis.admin` — reload/give and every emoji

An entry with a blank `permission` only requires `astraemojis.use`.

## Parsing behavior

`EmojiManager` is the single parser used everywhere. It replaces textual leaves while retaining Adventure styles and children. Unknown codes remain plain text, `\:name:` is unescaped without replacement, and codes inside URLs, inline code, or fenced code blocks are ignored.

## Supported surfaces

Paper listeners cover chat, signs, books, and anvil results. The optional ProtocolLib bridge deserializes outgoing JSON to Adventure components, performs component-level replacement, and serializes it back. This preserves sprite object components in tab headers/footers, scoreboard components, text-display/armor-stand metadata, inventory titles/items, boss bars, and dialogs when the installed ProtocolLib exposes those packet fields.

Item names and lore in outgoing inventory packets are transformed on a recipient-specific clone, not on the server-side item. Every surface can be disabled in `config.yml`.

Vanilla clients do not send completion requests while typing ordinary chat, so live `:name:` suggestions in the normal chat field require a client mod. `/emoji` arguments have server tab completion, and `/emoji list` provides click-to-copy codes.

## Public API

```java
Component parsed = AstraEmojisAPI.parse("Hello :netherite_sword:");
Component checked = AstraEmojisAPI.parse("Hello :netherite_sword:", player);
Optional<Emoji> emoji = AstraEmojisAPI.getEmoji("netherite_sword");
```

`AstraEmojisService` is also available from Bukkit's `ServicesManager`.

## Notes

* Native sprite emojis require Minecraft 1.21.9+ but no resource pack.
* Signed chat is changed through Paper's `AsyncChatEvent`, not by rewriting signed packets.
* Packet constants are discovered by name so missing version-specific packets do not prevent startup.
